## Problem Statement

O gestor precisa **consultar suas entrevistas**, preparar o contexto antes da conversa e **registrar a avaliação na ficha** (perguntas, parecer, recomendação), sem misturar com a agenda operacional completa do RH e sem duplicar o workspace de condução já existente.

Hoje: agenda RH em `#entrevistasPage`; condução em `#interviewConductDialog`; portal gestor tem nav Entrevistas que ainda aponta para a página RH; home do gestor lista só “próximas” de forma resumida.

## Anti-redundância

| Pergunta | Resposta |
|----------|----------|
| Já existe fluxo com o mesmo JTBD? | Parcial — condução + agenda RH + atalhos na home. **Estender** portal gestor + condução; **não** recriar ficha do zero. |
| Cabe em hub existente? | Sim — `#gestorPage` + nav Entrevistas já existente. **Sem** item novo na sidebar. |
| Informação já aparece em outro lugar? | Artefatos (fit/teste/currículo) no painel candidato; condução reutilizada; pendências de ficha continuam derivadas. |
| RH × Gestor mesmo fluxo? | Lista/contexto: hub gestor. Condução: compartilhada (estendida). Agenda RH permanece para o papel RH. |
| KPI/histórico duplicado? | Uma entrevista / um `conductDraft`; histórico da candidatura na finalização. |

**Evita:** segunda condução paralela; embutir `#entrevistasPage` no modo gestor; nova sidebar; reinventar catálogo de fichas.

## Scope

### In

- Hub **Minhas entrevistas** no Portal do gestor com buckets: Hoje · Próximas · Aguardando finalização · Realizadas · Canceladas
- Cards com: candidato, vaga, data, horário, tipo, entrevistadores, status, ficha vinculada
- Detalhe pré-entrevista: abrir candidato, currículo, requisitos da vaga, entrevistas anteriores, atalhos a avaliações/teste/Fit, abrir link da reunião
- Estender condução: pontos positivos / pontos de atenção; competências na finalização (quando houver); recomendações Avançar / Reprovar / Banco / Nova avaliação / Aguardar decisão; próxima etapa quando aplicável
- Regras: bloquear finalizar com obrigatórias vazias; ao finalizar registrar no histórico da candidatura
- Seeds dos estados: Reagendada, Cancelada, Não compareceu, ficha em rascunho, ficha concluída, aguardando finalização
- Wire nav Entrevistas (modo gestor) → hub; cache bump; `graphify update`

### Out

- Item novo na sidebar
- Nova modal de condução só-gestor
- Multi-entrevistador editando ao mesmo tempo
- Export PDF / backend / notificações reais
- Alterar catálogo `#fichasPage` além do necessário para competências na finalização
- Reimplementar agenda RH

## Surfaces

1. `#gestorPage` — hub lista (`homeFilter === "entrevistas"`), abas/buckets + cards  
2. `#interviewDetailDialog` — modo/contexto gestor com bloco “Antes da entrevista” + CTAs  
3. `#interviewConductDialog` — durante + finalização (estendido)  
4. `#gestorCandidatePanel` / `openCandidateResume` — deep-links de contexto  
5. Nav `data-page="entrevistas"` em modo gestor → hub (não `renderAgenda` RH)

**Buckets (critério protótipo, `TODAY_KEY`):**

| Bucket | Critério |
|--------|----------|
| Hoje | dia de `at` === hoje e status não terminal (Cancelada / Não compareceu) |
| Próximas | `at` > hoje e não terminal |
| Aguardando finalização | iniciada ou Realizada sem `finalizedAt` (ficha incompleta) |
| Realizadas | Realizada **e** (`finalizedAt` ou sem ficha exigida) |
| Canceladas | Cancelada \| Não compareceu |

## Status / ações

| Momento | Ações |
|---------|--------|
| Pré (detalhe) | Abrir candidato · Currículo · Ver requisitos · Anteriores · Fit/Teste/Avaliações · Link reunião · Iniciar / Continuar / Ver ficha |
| Durante | Responder · Editar · Anotações · +/− · Currículo · Autosave · Salvar rascunho · Continuar depois |
| Finalizar | Avaliação + parecer + recomendação · Finalizar (bloqueia se obrigatórias pendentes) |

Pós-finalizar: `status = Realizada`, `finalizedAt`, push histórico/atividades da candidatura com entrevistador + data/hora + recomendação resumida.

## UI notes

- Hub: padrão visual das Pendências do gestor (abas com `talent-tab-count` + lista de cards)
- Detalhe: bloco “Contexto” empilhado; CTAs primários conforme status
- Condução: manter layout atual; lateral ganha listas +/−; passo final ganha competências + novas opções de recomendação
- Empty por bucket

## Error / empty states

- Sem entrevistas no bucket → empty  
- Sem ficha vinculada ao iniciar → toast (pedir ficha / fallback alinhado à condução atual)  
- Obrigatórias pendentes → bloquear finalizar + listar  
- Link de reunião ausente → CTA desabilitado ou toast
