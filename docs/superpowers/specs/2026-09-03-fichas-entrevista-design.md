## Problem Statement

O RH precisa montar **modelos de fichas de entrevista** (instrumento do entrevistador), no espírito do PDF operacional Player: cabeçalho do candidato, perguntas numeradas, espaço de resposta e observações/parecer do avaliador.

Hoje só existe o stub `interviewSheets` (strings no select `#interviewSheet`). Testes técnicos cobrem prova do candidato — domínio diferente.

## Decisions

| Tema | Decisão |
|------|--------|
| Hub | Menu **Seleção** → página **Fichas de entrevista** (irmã de Técnicos) |
| Não usar | Configurações (revisado após o PDF real) |
| Abordagem | Catálogo completo (Approach A) |
| Tipo na listagem | = **Categoria** do modelo: RH · Técnica · Gestores |
| Tipos de pergunta | Texto curto · Texto longo · Sim/Não · Múltipla escolha · Escala · Nota |
| Vagas | Multi-select **no editor** do modelo |
| Agendamento | `#interviewSheet` lista só modelos **ativos** |
| Preencher ficha / scorecard | **Fora** desta onda |

## Scope

### In

- Página nova em Seleção: listagem + editor + preview
- CRUD completo de modelos e perguntas
- Ações: criar, editar, duplicar, visualizar, inativar/reativar, excluir quando permitido, adicionar/duplicar/reordenar perguntas, vincular vagas, pré-visualizar ficha
- Integração: popular `#interviewSheet` a partir dos templates ativos
- Seeds: 3 modelos (RH / Técnica / Gestores); um espelhando o PDF (perguntas abertas + bloco de observações no preview)
- Cache bump

### Out

- Preencher respostas / parecer na entrevista ou no dossiê
- Scorecard pós-entrevista
- Export PDF real
- Alterar agenda além do select da ficha
- Misturar com `#tecnicosPage` / `tests[]`

## Surfaces

1. **Nav Seleção** — item “Fichas de entrevista” (`data-page="fichas"`)
2. **Listagem** — `#fichasPage` / lista com colunas e ações
3. **Editor** — metadados + builder de perguntas + vínculo de vagas
4. **Preview** — dialog estilo ficha (cabeçalho + perguntas + “Observações do avaliador”)
5. **Agendamento** — `#interviewSheet` alimentado pelos templates ativos

## Data model

```text
interviewSheetTemplates[]:
  id, name, description
  category: "RH" | "Técnica" | "Gestores"
  active: boolean
  updatedAt: ISO date string (demo clock)
  jobIds: number[]          // vagas vinculadas
  questions[]:
    id, prompt, type, required, order
    options?: string[]      // múltipla escolha / labels de escala

question types:
  short_text | long_text | yes_no | single | scale | score
```

Entrevista: campo `sheet` passa a referenciar o template (id + label no select). Seeds antigos com string livre são migrados/normalizados para um template seed.

## Listagem

| Coluna | Fonte |
|--------|--------|
| Nome | `name` |
| Tipo | `category` |
| Vagas vinculadas | contagem / nomes via `jobIds` |
| Quantidade de perguntas | `questions.length` |
| Status | ativo / inativo |
| Última alteração | `updatedAt` |

### Ações

| Ação | Regra |
|------|--------|
| Criar / Editar | Abre editor |
| Duplicar | Cópia com nome “ (cópia)”, status ativo |
| Visualizar | Preview read-only |
| Inativar / Reativar | Toggle `active` |
| Excluir | Só se **inativo** e **nenhuma entrevista** referencia o template |
| Pré-visualizar ficha | Mesmo preview (layout tipo PDF) |

## Editor

- Campos: nome, descrição, categoria, vagas (multi-select das `jobs`), status
- Perguntas: adicionar, duplicar, editar, excluir, obrigatória, reordenar ↑↓
- Tipos com UI adequada (options para `single`/`scale`; faixa para `score` se necessário no protótipo)
- Preview: cabeçalho (Nome / Cargo / Telefone placeholders) + perguntas numeradas + bloco fixo **Observações do avaliador** (não é pergunta editável nesta onda)

## Integração com agendamento

- Remover/substituir array stub `interviewSheets`
- `fillInterviewSheetOptions(selected)` lê `interviewSheetTemplates.filter(t => t.active)`
- Select mostra `name`; valor preferencialmente `id` (com fallback amigável no detalhe)

## Overlap / não redundante

| Existente | Relação |
|-----------|---------|
| Técnicos | Padrão UI a **espelhar**, entidade separada |
| `interviewSheets` stub | **Substituído** |
| Agenda / ciclo de vida | Só o select da ficha |
| Configurações | Não hospeda o hub |
