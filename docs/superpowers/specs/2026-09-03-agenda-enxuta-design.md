## Problem Statement

A página Entrevistas já gerencia o ciclo de vida das entrevistas, mas a visualização de agenda ainda é parcial (lista + mês). RH precisa de um hub Dia / Semana / Mês com filtros, sem duplicar ações já existentes no modal.

## Scope (enxuto)

**In:**
- Toggle de visualização: Dia | Semana | Mês (default: Semana)
- Eventos no grid com candidato, horário, status (+ badge Atrasada)
- Clique abre `#interviewDetailDialog` existente
- Criar entrevista via formulário existente
- Filtros: recrutador, gestor, vaga, empresa, modalidade (tipo), status
- Empty state quando não há eventos no recorte filtrado
- Reusar seeds de conflito / atrasada / aguardando resultado

**Out:**
- Nova página de menu
- Duplicar ações no card do grid (exceto abrir)
- Portal do candidato
- Sync de calendário externo

## Decisions

| Tema | Decisão |
|------|---------|
| Hub | Página Entrevistas atual |
| Default | Semana |
| Ações | Modal de detalhe + “Nova entrevista” |
| Fonte | `interviews[]` + helpers do ciclo de vida |

## Surfaces

1. Toolbar: Dia | Semana | Mês + filtros + Nova entrevista
2. Grid Dia: timeline horária do dia selecionado
3. Grid Semana: 7 colunas (dom–sáb) com slots/eventos
4. Grid Mês: calendário mensal existente evoluído
5. Empty: mensagem + CTA criar / limpar filtros
