# Design: Scorecard (critérios, avaliação e Score Geral)

Generated by brainstorming on 2026-09-04  
Repo: Prototipação Vagas (local)  
Status: APPROVED  
Mode: Builder  
Approach: 1 — Hub em **Resultados** com abas (Scorecards · Avaliações) + modal de composição + dossiê + alertas

## Problem Statement

O protótipo precisa definir **como critérios de seleção e pontuação são configurados e analisados**: scorecard por vaga, avaliação por candidato, Score Geral composto e alertas de pendência / critérios sem nota.

Hoje existem módulos isolados (Entrevistas, Testes, Fit Cultural, Fichas) e a página **Resultados** quase vazia. Não há template unificado de Score Geral, avaliação híbrida (auto + manual) nem comparação estruturada por composição.

Scorecard estava **fora de escopo** em fichas/ciclo de entrevistas; esta onda preenche essa lacuna.

## Decisions

| Tema | Decisão |
|------|--------|
| Relação Scorecard × Score Geral | **A** — o Scorecard *é* o template do Score Geral (6 blocos) |
| Navegação | **B** — hub dentro do item existente **Resultados** (sem nav nova) |
| Origem das notas | **A** — híbrido: auto dos módulos quando houver dado; senão manual + alerta |
| Critérios | **A** — 6 blocos fixos; configurar peso, nota mínima, responsáveis; desligar = peso 0 / `enabled: false` |
| Profundidade MVP | **A** — ciclo completo (CRUD, vincular, avaliar, revisar, composição, comparar, alertas, dossiê) |
| Abordagem | **1** — espelhar padrão Testes/Fit (hub + abas + modal + dossiê) |
| Persistência | Em memória no protótipo |
| Avaliador no portal candidato | Fora — só RH/gestor |

## Scope

### In

- Reaproveitar nav **Resultados** → `#resultadosPage` como hub de Scorecard
- Abas **Scorecards** · **Avaliações** com contagens
- Banner/resumo de alertas: avaliações pendentes + critérios enabled sem nota
- **Scorecard**: nome; vaga; 6 critérios fixos; peso %; nota mínima; responsáveis; enabled
- Soma dos pesos dos critérios **habilitados** = 100%; **bloquear salvar** se ≠ 100 (aviso visual no editor)
- Ações scorecard: Criar · Editar · Duplicar · Vincular à vaga
- MVP: **um scorecard ativo por vaga** (trocar vínculo avisa se já houver avaliações)
- **Avaliação**: por candidato + scorecard/vaga; critério; nota 0–100; comentário; avaliador; `source: auto|manual`
- Status: `Pendente` · `Parcial` · `Completa` · `Em revisão`
- Score geral = média ponderada dos critérios enabled **com nota**; faltando nota → não Completa + alerta
- Chip “abaixo do mínimo” se nota < `minScore` (não bloqueia fluxo no protótipo)
- Preenchimento auto:
  - Fit Cultural → aderência de assignment concluído
  - Técnico / Comportamental / Competências → % do teste aplicado do tipo (mais recente concluído)
  - Entrevista → nota de condução/ficha se existir; senão pendente manual
  - Gestor → manual (ou stub do portal gestor se já houver score)
- Modal: visualizar composição; Avaliar / Revisar; atualizar da fonte (auto); Mais ações
- Comparar 2–3 candidatos **mesma vaga** (geral + 6 blocos)
- Dossiê: bloco Score/Resultados com composição, CTA Avaliar/Revisar, badge de pendência
- Seeds: ≥1 scorecard vinculado; avaliações em status variados (completa, parcial, pendente)
- Cache bump

### Out

- Critérios livres / scorecards com blocos arbitrários
- Vários scorecards ativos na mesma vaga
- Workflow multi-nível de aprovação / calibração estatística
- Portal do candidato preenchendo scorecard
- Backend / persistência real
- Export PDF / relatórios avançados
- Motor de ranking global além do comparar lado a lado

## Surfaces

1. **Nav** — `data-page="resultados"` → `#resultadosPage` (reforçada)
2. **Aba Scorecards** — lista/editor de templates
3. **Aba Avaliações** — lista de avaliações + seleção para comparar
4. **Modal avaliação / composição** — detalhe + avaliar/revisar
5. **Modal comparar** — 2–3 candidatos
6. **Dossiê candidato** — bloco Score Geral + alertas + CTAs

## Data model

```text
SCORE_CRITERIA = entrevista | fitCultural | tecnico | comportamental | competencias | gestor

scorecards[]:
  id, name
  jobId?, vacancyTitle?
  active: boolean
  criteria[]: {
    key: SCORE_CRITERIA
    enabled: boolean
    weightPct: number
    minScore: number
    assigneeIds: number[]   // responsáveis (seed de usuários/RH/gestor)
  }

scoreEvaluations[]:
  id, candidateId, scorecardId
  jobId?, vacancy
  status: Pendente | Parcial | Completa | Em revisão
  scores[]: {
    criterionKey: SCORE_CRITERIA
    score: number | null      // 0–100; null = sem nota
    source: auto | manual | null
    comment: string
    evaluator: string
    updatedAt: string | null
  }
  overallScore: number | null  // ponderado; null se nenhum critério enabled com nota
  createdAt, updatedAt
```

### Regras

- Só critérios `enabled: true` entram no Score Geral e nos alertas de “sem nota”.
- `enabled: false` ≡ desligado (peso tratado como 0; não exige nota).
- Ao abrir/criar avaliação: tentar preencher `source: auto` a partir das fontes; campos sem fonte ficam `score: null` → pendência.
- Revisar: permite editar notas `manual`; auto pode ser sobrescrita manualmente no protótipo (marca `source: manual`) ou “Atualizar da fonte” restaura auto.
- Um scorecard ativo por `jobId`/`vacancyTitle` no MVP.

## Status machine

```text
Criar avaliação (dossiê/hub) → Pendente (nenhuma nota) ou Parcial (algumas auto)
Preencher/salvar notas parciais → Parcial
Todos enabled com nota → Completa
Ação Revisar → Em revisão (volta a Completa ao salvar de novo com tudo preenchido)
```

## UI notes

- Header Resultados: título/subtítulo alinhados a Scorecard; primária **Novo scorecard** na aba Scorecards; na aba Avaliações, CTA **Comparar** (ou botão na lista) exige 2–3 selecionados
- Lista Avaliações: score geral, status, chips dos blocos sem nota / abaixo do mínimo
- Modal: breakdown por bloco (peso, nota, fonte, min, responsável); não duplicar ações que só mudam de aba
- Comparar: mesma vaga; toast se seleção inválida
- Dossiê: se a vaga não tiver scorecard → CTA “Criar/vincular scorecard” ou empty state claro

## Error / empty states

- Scorecards vazio → empty + Novo scorecard
- Avaliações vazio → empty + CTA pelo dossiê
- Pesos ≠ 100% nos enabled → aviso no editor + **bloquear salvar**
- Comparar <2 ou >3 → toast
- Sem scorecard na vaga ao Avaliar → toast + atalho para criar/vincular

## Testing (manual)

1. Resultados → abas Scorecards / Avaliações com seeds
2. Criar scorecard, ajustar pesos (100%), vincular vaga; duplicar
3. No dossiê: Avaliar → notas auto (Fit/testes) + pendências manuais (ex. Gestor)
4. Completar manuais → Completa; ver composição
5. Revisar nota manual; “atualizar da fonte” em bloco auto
6. Alertas no hub e badge no dossiê para Parcial/Pendente
7. Comparar 2 candidatos da mesma vaga
8. Critério desligado não entra no geral nem no alerta de sem nota
